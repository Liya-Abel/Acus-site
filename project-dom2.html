Каркасные дома

Каркасный дом
130 м² — люкс.

Дом люкс-класса на свайном фундаменте с обвязкой из досок. Каркас собран по проекту из сухого строганного материала, обшит планкеном. Двускатная кровля из гибкой черепицы с утеплением 300 мм. Построили за 3 месяца — дом сдан и в нём живут.

01
Этап первый

Фундамент

Свайно-винтовой фундамент с обвязкой из досок — надёжное и практичное решение для каркасного дома. Сваи вкручиваются без земляных работ, не нарушая участок, и служат десятилетиями. Обвязка из качественной доски формирует ровное основание для каркаса.

02
Этап второй

Каркас и стены

Каркас собран по проекту из сухого строганного материала — это важно для точности геометрии и долговечности конструкции. Стены утеплены минеральной ватой 250 мм, снаружи обшиты планкеном. Всё выглядит как классический деревянный дом, но с современными характеристиками теплосбережения.

03
Этап третий

Кровля

Двускатная кровля из гибкой черепицы. Утепление кровли 300 мм обеспечивает отличное теплосбережение. Стропильная система смонтирована с точным соблюдением углов и нагрузок, рассчитана на снеговые условия Ленинградской области.

Результат

Дом сдан.
Там живут.

Фотографий готового дома у нас не сохранилось — строители забыли снять, потому что были заняты следующим объектом. Это, пожалуй, лучший знак: когда работа сделана хорошо, о ней просто не думают — ею пользуются.
